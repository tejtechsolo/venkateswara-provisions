# Venkateswara Provisions

Wholesale commerce and store-management SaaS.

Built directly with ChatGPT-connected development tools, without Lovable.

## Planned stack
- Next.js App Router + TypeScript
- Supabase/Postgres + Auth + Row Level Security
- RBAC for admin and customer roles
- Wholesale catalog, customer pricing, inventory, cart and orders
- Admin dashboard and reporting
- Integration hub for Airtable, Notion, GitHub, Vercel and Canva
